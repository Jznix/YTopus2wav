YTopus2wav

A lightweight macOS menu bar app for downloading YouTube audio and converting it to WAV.

Features

- Download YouTube audio
- Convert audio to WAV
- Save files directly to ~/Downloads
- Runs in the macOS menu bar
- Simple menu with Download and Quit
- Bundled FFmpeg

Requirements

- macOS
- Apple Silicon (ARM64)

Usage

1. Start YTopus2wav.
2. Copy a YouTube link.
3. Use the Download option.
4. The converted WAV file is saved to your Downloads folder.

Tech Stack

- Python
- yt-dlp
- rumps
- FFmpeg
- PyInstaller
